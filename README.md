# Elisava Business Studio

Validation prototype. Companies submit real business problems; Elisava builds a team (students accepted by professors, an alumni mentor and a professor as project leader) and works as the contractor.

Live: https://elisava-exchange.netlify.app

- Single static `index.html` (fonts, logo and demo reports embedded)
- Challenge submissions and the validation survey are sent to Netlify Forms (`challenge`, `feedback`)
- Demo project data lives in the visitor's browser (localStorage)
